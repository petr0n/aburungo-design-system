Scenario card B — does the tag hold on every accent?

Option B puts a scenario tag on a saturated strip with the crest debossed over it. The four accents are nowhere near the same lightness — Ai-iro is near-black, Ōgon is a light gold — so one tag treatment cannot sit on all four. Every number below is measured from the rendered pixels, crest included, not computed from the token values.

1 · Paper pill — the treatment the option-B mockup used

A warm-paper pill with Ai-iro text. The number is the pill against the strip it sits on: this is whether the pill reads as a shape at all, so the bar is 3:1.

3 · The strips side by side, no tag — the lightness spread

The root cause. These are the same crest at the same opacity on each accent. Any single tag style has to work on all four of these grounds.

4 · The bigger problem this turned up — accent-rokusho-fg fails on its own accent

Not a scenario-card issue. PhraseCard ships bg-accent-rokusho text-accent-rokusho-fg today, and that pair is flat colour on flat colour — no crest involved. None of the four accent pairs were gated. Numbers below are computed live from the tokens in this page, so they cannot go stale.
